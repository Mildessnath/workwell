Frame Treatment & Sizing

  • •White Circular Frame: Always wrap Peekaboo PNGs in rounded-full bg-white object-contain p-1. Never use object-cover or crop/stretch the 512×512 artwork.
  • •Desktop Sizing: Central orbital core 112×112px (w-28 h-28), Playtime core 128×128px (w-32 h-32), Tip/Insight pill 44×44px, Sensor satellites 44×44px.
  • •Mobile Sizing: Central orbital core 72–80px, Tip/Insight pill 40×40px, Sensor satellites 24–28px.
devices

Spacing, Positioning & Responsive Usage

  • •Orbital Geometry: Peekaboo sits at the center of concentric dashed/solid lilac rings with a dashed electric-violet beam pointing to the currently selected cardinal satellite.
  • •Desktop (1280–1440px): Persistent 224px left sidebar, top header with mood/range pills, central orbit stage, and right-hand telemetry inspector card.
  • •Mobile (390px): Compact 328–336px orbital stage stacked above a single focused telemetry card, anchored by a fixed 5-tab bottom navigation bar.
